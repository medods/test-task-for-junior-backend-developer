## ТЕСТ-КЕЙСЫ: Создание повторяющихся задач

1. Единоразовая задача
  
Запрос:
```
{
"title": "Единоразовая задача - консультация с кардиологом",
"description": "Обсудить результаты ЭКГ с д-ром Смирновым",
"status": "new",
"scheduled_at": "2026-04-25T10:00:00Z"
}
```

Ожидаемый результат:
- Создается 1 задача
- recurrence = null
- is_recurring_template = false

2. Ежедневная задача (каждые 2 дня) без указания количества
  
Примечание: Будет установлено дефолтное количество - 90 экземпляров

```

"title": "Ежедневная задача (каждые 2 дня) - без лимита",
```

- Создается шаблон

### 12. Тесты валидации RecurrenceConfig

12.1. DAILY - граничные значения

Успешные сценарии:
- Daily = 1 (минимальное значение)
- Daily = 31 (максимальное значение)
- repeat_count = 1 (минимальное)
- repeat_count = 365 (максимальное)

Ошибочные сценарии:

A. Daily = 0 (меньше 1)
```
{
"title": "Ошибка валидации - daily меньше 1",
"description": "Должна быть ошибка",
"status": "new",
"scheduled_at": "2026-04-25T10:00:00Z",
"recurrence": {
    "type": "daily",
    "Daily": 0,
    "repeat_count": 10
    }
}
```
Ожидаемая ошибка: "Периодичность для ежедневных задач не может быть меньше 1 дня"

B. Daily = 32 (больше 31)
```
{
"title": "Ошибка валидации - daily больше 31",
"description": "Должна быть ошибка",
"status": "new",
"scheduled_at": "2026-04-25T10:00:00Z",
"recurrence": {
    "type": "daily",
    "Daily": 32,
    "repeat_count": 10
    }   
}
```
Ожидаемая ошибка: "Периодичность для ежедневных задач не может превышать 31 дней"

C. repeat_count = 366 (больше 365)
```
{
"title": "Ошибка валидации - repeat_count превышает лимит",
"description": "Должна быть ошибка",
"status": "new",
"scheduled_at": "2026-04-25T10:00:00Z",
"recurrence": {
    "type": "daily",
    "Daily": 2,
    "repeat_count": 366
    }
}
```
Ожидаемая ошибка: "Количество создаваемых задач не может превышать 365"

## Правила работы с шаблонами и экземплярами

1. Изменение родительского шаблона
    - Изменения применяются ко всем будущим экземплярам задачи

2. Изменение экземпляра шаблона
    - Родительский шаблон НЕ изменяется
    - Экземпляр становится самостоятельным

3. Удаление родительского шаблона
    - Все связанные экземпляры удаляются каскадно

4. Дефолтное количество экземпляров
    - Если repeat_count не указан:
        * daily: 90 экземпляров
        * monthly: 24 экземпляра
        * parity: 90 экземпляров
        * specific_dates: НЕТ ДЕФОЛТА (берутся все указанные даты)

5. Изменение repeat_count в шаблоне
    - Количество экземпляров увеличивается или уменьшается соответственно

6. Изменение типа шаблона
    - Все экземпляры пересоздаются по новому типу

7. Изменение четности (parity)
    - Все экземпляры пересоздаются
    - Производится сдвиг относительно scheduled_at

## Таблица дефолтных значений

| Тип повторения     | Дефолтное количество repeat_count |
|--------------------|-----------------------------------|
| daily              | 90 (3 месяца)                     |
| monthly            | 24 (2 года)                       |
| parity             | 90 (~3 месяца)                    |
| specific_dates     | Нет дефолта (берутся все даты)    |
